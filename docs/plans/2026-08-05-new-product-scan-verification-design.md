# 新建商品编码二次扫码验证设计

## 目标

降低扫码枪误读造成厂家条码、仓配编码和平台商品 ID 错绑的风险。功能作用于新建和编辑商品，不改变查询流程。

## 设置

系统设置使用 `AppSetting` 保存到 SQLite，键名为 `new-product-scan-verification`。设置包含一个总开关，以及平台商品 ID、商品级仓配编码、规格厂家条码、规格仓配编码四个独立开关。总开关关闭时保留各分项状态，重新开启后继续生效。

## 验证流程

启用验证的编码首次录入并按回车或离开输入框后，打开二次扫描弹窗并自动聚焦。第二次扫描与第一次去除首尾空白后完全一致，输入框才标记“已验证”。两次不一致、关闭弹窗或点击遮罩取消时，第一次和第二次内容全部清空，并提示重新扫描。

父表单记录每个动态规格和平台行的验证状态。编码发生任何修改都会撤销已验证状态；保存前再次检查全部非空编码，存在未验证项时禁止提交。关闭对应分项开关后，该类编码恢复普通输入，不要求验证。

编辑页面把加载时的已有编码视为可信旧值，未修改时不要求重新扫描。只有新增编码或值发生变化时才撤销可信状态并启动二次验证；如果修改后恢复为原值，也继续视为可信旧值。

## 验证

- 设置结构测试覆盖默认值和缺失字段。
- 类型检查与生产构建覆盖页面和接口集成。
- 浏览器流程覆盖匹配成功、不匹配清空、取消清空、分项关闭和保存拦截。
