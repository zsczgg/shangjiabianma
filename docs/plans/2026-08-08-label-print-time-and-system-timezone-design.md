# 标签打印时间与系统时区设计

## 系统时区

系统设置新增时区选择，支持北京时间 `Asia/Shanghai` 与首尔时间 `Asia/Seoul`。选择结果保存到现有 `AppSetting` 表，不新增数据库表。顶部实时时钟、商品更新时间、修改历史和 API 管理页面的可视时间统一读取该设置。数据库和对接 API 仍保留标准时间，不改写历史数据。

## 标签打印时间

标签内容新增“打印时间”，默认开启，并默认显示年、月、日、时、分、秒。用户可以分别关闭各时间组成部分，调整字号，并从顶部左/中/右、底部左/中/右六个稳定位置中选择。标签不额外打印时区名称，但时间数值始终按照系统当前时区计算。

标签预览每秒刷新。点击打印时捕获同一个时间点，整批标签使用完全相同的打印时间，避免大量标签跨秒后出现时间不一致。打印时间使用绝对定位，不改变现有条码排版，并针对 40×30 标签限制字号和边距，防止裁切。

## 兼容与持久化

旧版标签设置读取时自动补齐新的时间配置，不会重置纸张、份数、备注或其他已有偏好。系统时区和标签配置均保存在 SQLite 数据库中，浏览器刷新、容器重启或更换设备后仍然有效。

## 验证

覆盖旧设置迁移、北京与首尔时差、时间组成格式、标签配置校验和打印时间固定逻辑；运行完整测试、类型检查和生产构建，并验证设置保存、实时时钟及三种标签预览。
