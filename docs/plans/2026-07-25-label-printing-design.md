# 标签打印中心设计说明

## 目标

在现有商品编码系统中增加专业标签打印能力，支持 70×50 mm 与 100×100 mm 单列热敏标签纸。用户可以从商品详情快速打印某个规格，也可以在独立打印中心搜索、批量选择并设置份数。

## 已确认的打印方式

- 使用浏览器标准打印窗口，兼容不同品牌标签机。
- 使用 CSS 毫米单位和动态 `@page` 精确控制纸张尺寸。
- 提供横向、纵向毫米偏移校准，校准值保存在当前浏览器。
- 代码结构预留以后接入本地静默打印服务的可能。

## 选定视觉方向

采用“预览主导”布局：

- 左侧：可搜索的批量打印队列与每项份数。
- 中间：大尺寸、按实际比例显示的标签预览。
- 右侧：内容显示开关、自定义备注与打印校准。
- 顶部：纸张尺寸、默认份数、恢复默认和打印操作。

延续现有蓝白企业后台风格。标签本身保持黑白、扫码优先、留白充分，不使用装饰性渐变或二维码。

## 标签内容

默认显示：

- 媛媛和小肥朱
- 商品名称
- 规格
- 内部编码文字
- 内部编码 Code 128 条形码

可选显示：

- 厂家条码及 Code 128
- 商品级或规格级菜鸟云仓编码及 Code 128
- 淘宝、闲鱼、小红书、其他平台 ID 及 Code 128
- 商品图片
- 自定义备注

## 行为规则

- 默认仅列出使用中的商品和规格；停用数据不能加入新的打印任务。
- 每个规格单独生成标签，内部编码不可编辑。
- 一次打印任务只能选择一种纸张尺寸，避免浏览器混合纸张分页不可靠。
- 每个队列项目可设置独立份数，打印页按份数展开。
- 打印时只显示标签纸内容，不显示后台导航、编辑面板或浏览器页面布局。
- 缺失的可选字段自动隐藏，不留下空白标题。
- 条码保留足够左右静区，不允许内容将主要条码压缩到不可扫。

## 两种模板

### 70×50 mm

紧凑仓储标签。内部编码和主条码占据最大视觉权重，商品名、规格、品牌位于上方；外部编码采用单列紧凑区，内容过多时优先保证主条码。

### 100×100 mm

完整信息标签。商品信息、商品图片、主条码和外部编码分区展示，可容纳厂家条码、菜鸟编码、平台 ID 与备注。

## 验收重点

- 打印预览尺寸比例正确。
- 70×50 与 100×100 的 `@page` 尺寸准确。
- 批量选择、搜索、份数、内容开关和校准可工作。
- Code 128 在屏幕预览和打印 DOM 中均能生成。
- 打印页面无额外页边距、页眉页脚和后台 UI。
- 窄屏下可操作，但主要使用场景按桌面端优化。
